# R33 桌面交互与上下文显示修复

修复范围：

- 自由分栏菜单直接以触发按钮定位，打开后按真实尺寸限制在窗口内；
  不再依赖共享 React 是否支持 beforetoggle，保留非模态原生 popover。
- Codinput 保持原输入增强功能，移除其全局标签 pointerdown 拦截；
  标签换位、分栏和浮动手势交还原生 dockkit。
- 任务图背景拖拽只屏蔽本次拖拽末尾的点击。
  下一次点击节点、展开组或控件会清除上次移动距离。
- 子代理任务与上下文建议使用独立的原生顶层 dialog，
  不再被图谱 transform、缩放或栏宽挤压；宽窗口两列、窄窗口一列，
  内容滚动，右下角支持拖动调整大小；Escape 关闭并释放原生焦点限制。
- 子代理图谱与输入框共用上下文汇总规则：
  有效下一请求的服务端校准优先；恢复后缺失或为零且当前内容非空时，
  使用当前保留内容估算。累计计费与压缩前旧占用不充当当前总量。
- 无有效 token 的全零 usage 暂存到响应终止：
  成功仍交给原生驱动，失败则丢弃占位样本；
  正用量（包括全缓存输入）的失败响应继续如实计费。
- PI 适配器文本中明确的上下文超限标记会归入正式超限恢复；
  原生压缩必须证明提交并缩减后才能重试，不能根据压缩邻近或
  单独的 PI_AI_ERROR 推测超限。
