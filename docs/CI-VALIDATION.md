# CI 桌面渲染测试

GitHub Actions 的 Windows runner 执行构建、类型检查、全量测试和安装包审计。
DOM 回归使用独立临时浏览器配置，不访问用户的 DSH 或浏览器配置，不调用模型。
这些测试不代替真实 DSH Desktop 整体交互验收。

2026-10-23 的 `af6c544` 检查失败于桌面交互测试的浏览器启动阶段：
12 秒内未读取到 `DevToolsActivePort`，界面断言尚未开始。
当时浏览器输出被丢弃，现有日志无法判断是进程退出、文件缺失还是启动较慢。
这不构成插件注册逻辑失败的证据，也不能仅凭本机通过宣称 CI 通过。

交互回归现通过子进程独占的 CDP 管道通信，不创建远程调试端口、不轮询端口文件，
也不会连接任何已运行的浏览器。以 `Browser.getVersion` 响应确认启动，
启动预算为 30 秒；进程退出或管道失败会立即返回具体错误。
失败信息保留浏览器输出末尾和退出码，写入测试日志并由现有工作流上报。
运行结束关闭本次测试拥有的进程并清理临时目录，不降低界面断言、不自动重跑掩盖失败。
