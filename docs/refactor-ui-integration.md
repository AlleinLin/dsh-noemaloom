# 原插件界面整合

本次修改只写入 `nexus`。保留宿主工作区树、会话、输入框、文件/Git/终端右侧栏，以及现有 Logo。全局外观使用既有 Claude 色板；共享 tokens 也供原插件画布继承，圆角按现有等级统一。

## 界面归属

| 功能 | 主实现与入口 |
| --- | --- |
| 文件、Git、终端 | 宿主原生右侧栏 |
| 会话阅读 | 原生 `chat`，迁入 Better Display 正文、MCP、动效与产物增强；旧 `reader` 迁移到 `chat` |
| 上下文分析与轨迹 | 原 Context，会话标签 `context` |
| 子智能体树与分析 | 原 BetterSidebar `SubagentView`，会话标签 `nexus.agents`，共享原 store |
| 原工作流运行监控 | 原 Fleet，会话标签 `fleet` |
| 思维图谱 | 原 ThoughtDAG，会话标签 `nexus.thoughtdag` |
| 会话图谱 | 原 Synapse，会话标签 `nexus.synapse` |
| 任务看板 | 原 TaskBoard 侧栏入口 `task-board` |
| 记忆与知识 | 原 Mnemon 侧栏入口 `mnemon` |
| 执行工作流编排 | Nexus `WorkflowEditor`，会话标签 `nexus.workflow`；全局与工作区在执行计划入口中提供对应编辑器 |
| 质量、审查、恢复、工程产物 | Nexus 补充页，按当前层级过滤 |
| 全局资源与设置 | 宿主侧栏的资源与管理，以及宿主设置中的 Nexus 小节 |
| 自由分栏 | 扩展原右侧栏 DockSurface，最多六栏、上下与左右嵌套、原生标签拖动及浮动；视图可跟随或固定会话 |
| 任务规划 | 原 TaskBoard 和原子代理树中的增量推断摘要，支持人工覆盖和三级分析设置 |
| 实时命令 | 原会话工具卡打开原底部工作台中的命令监视，读取原执行通道的增量输出；原交互终端保持独立过程身份 |

`adaptOriginalClientContext()` 通过 Cordis `extend()` 仅适配 slots 的位置与顺序，保留原组件、原 injector、服务访问和清理生命周期。它不改写宿主 Context，不创建第二个应用壳。Context 的重复右侧栏注册被屏蔽，原插件桥固定使用会话标签。

## 三层范围

- 全局入口管理模板、蓝图、资源、扩展、连接配置及跨工程记录。
- 工作区入口提供工程执行计划、质量、审查、恢复、产物和工程连接。
- 会话入口使用宿主传入的确切 `sessionId`；分析、图谱、工作流与会话工具直接在原会话切换。

工作区未选择时不借用第一个工作区；会话视图不借用侧栏当前选中的另一会话。辅助页按层级过滤，原插件完整功能通过其原生入口进入。

## 可视化工作流

原 Fleet 负责显示宿主运行；新的拖动编辑器负责定义可执行过程，二者职责不同。编辑器直接保存与运行统一的 `TaskPlan/Run`，不把拖动布局当成执行结果。

编辑器支持节点拖动与方向键移动、缩放、两类连线、节点模型/参数/指令、输出合同、独立验证、最终交付节点和预算：

- 数据连线编译为依赖边及 `inputRefs: ["node:<上游节点ID>"]`；只允许模型消费节点接收。后端校验本计划祖先依赖及本 Run 成功产物身份、内容 hash 和大小。
- 完成依赖只控制顺序，可选依赖保留原语义；人工节点仅能提供完成依赖。
- 保存调用 `workflow/plan` 冻结计划与布局；编辑后不能运行旧冻结身份。
- 全局和工作区保存各自模板/计划，会话提供运行按钮。已存在计划的交付验证、授权引用与可选依赖在编辑往返中保留。
- 模型列表使用宿主真实 provider/model 代号；缺省思考强度由后端选该模型最高支持值，显式值在保存前核验。
- 草稿在本机按全局/工作区/会话分别保存，读取时检查可显示结构。启动使用持久化幂等键；未知回执重试复用同一个键。
- 状态使用有界 `workflow/wait`，仅当前活跃且桌面可见时持续等待；卸载停止等待。查看结果按需调用 `artifact/get`。
- 暂停、继续、查询原运行、取消和人工完成使用对应真实操作。关闭监控仅关闭当前监控。完成后再次运行才新建幂等键。
