# ThoughtDAG 上游适配

Noemaloom 固定使用 npm 发布的 `dsh-thoughtdag@0.5.21`，来源为
[chenxiachan/thoughtdag](https://github.com/chenxiachan/thoughtdag/tree/main/dsh)，
沿用 MIT 许可。依赖与归档完整性记录在 `package-lock.json` 和
`sources.lock.json`，发布包许可保留于 `notices/originals/thoughtdag/`。
原有选取源码的图谱基础模块来自单独记录的历史快照，其来源标记不随 npm
运行时更新而改写。

新版的宿主网页搜索、工具精确步骤的会话授权、原生问题表单、权限模式与更新历史
均保留。网页搜索使用宿主 `ctx.web.search`；上下文编译、图谱导入和生成仍走上游
实现。图谱发起的新会话继续由 Noemaloom 的原生控制器创建，并记录来源。

Noemaloom 负责安装和更新依赖，所以集成画布跳过独立插件的版本查询与
“重新添加 dsh-thoughtdag”提示。该处理只替换已审核客户端中的
`bootPluginUpdateCheck` 函数；普通错误提示、版本更新历史和首次更新说明保留
原字节。画布里的更新历史仍可查看。

宿主与客户端的适配均固定审核过的 SHA-256，遇到上游内容变更时构建会停止，
需要重新审核。宿主新增的网页搜索、步骤参数规范化、流式搜索循环、权限预设实现，
以及客户端其他顶层函数，均进行原字节保留检查。

工具授权和问题表单只由当前图谱自己发起、已精确认领的活动轮次接管。回答必须
来自同一全局、工作区或会话范围。会话级工具授权同时绑定原生 Agent 实例和图谱
范围；实际参数变化需要重新授权，上游忽略的描述文字字段仍按上游规则处理。
Agent 释放和插件卸载清除内存授权，重启后需要重新确认。

画布的 `auto`、`allow` 权限模式仍映射至宿主可用的权限预设。只有图谱自己的
轮次开始后才临时应用，轮次结束立即恢复；排队期间和其他用户轮次不应用。
宿主不支持的模式以及无法安全恢复的自定义权限组合按上游行为报告不可用。
关闭 HTTP 流和卸载只取消该图谱请求拥有的活动轮次。问题等待器无论正常回答、
取消、关闭或卸载都会移除中止监听器和计时器。

`tests/thoughtdag-adapter.test.mjs` 执行适配后的版本检查函数和真实网页搜索
函数，并检查原字节保留与等待器清理；`tests/canvas-original-host.test.mjs`
通过构建后的发布宿主代码覆盖范围、表单、授权和权限生命周期。测试使用本地
替身服务，不请求真实模型。

2026-10-21 验证：构建、类型检查、1987 项全量测试、产物检查和实际安装包审计通过。
独立临时 profile 的真实 DSH 桌面端已加载新版画布；观察到独立版本查询为零，
没有出现插件升级提示。此桌面检查没有请求真实模型。
