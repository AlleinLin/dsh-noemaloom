# R41：上游同步与 Forge rc.3 适配

逐项审查152项来源；升级14个npm插件，重基Cognition 0.9.16、ACP kernel 0.0.169、
memsearch 0.4.23和Codinput 0.3.6。当前支持宿主仍为Desktop 0.2.1-rc.3；
0.2.2-alpha.2只作为候选评估，没有自动替换用户宿主或混升SDK。

本地原创Forge从0.1.4升级到0.1.5，同步引擎、SDK、官方standard预设、
构建与安装说明。独立官方rc.3实测拒绝旧包、接受新包，实际文件与PowerShell工具、
默认预设、卸载恢复和桌面执行通过，无版本豁免。Forge单独可选安装。

本批实际通过：2393项主回归、58个Cognition模块及全量Python编译、
78项dshell回归、21项真实桌面场景、109项Forge回归，
根项目与Forge npm审计均为0漏洞。完整构建、类型检查、产物与最终tgz审查均通过。
R40子代理压缩、上下文缓存与持久化重试链、三级隔离、原生入口及Claude主题均保留。

桌面首轮安装包与最终包逐项对比1617个文件，只有根目录两份README不同；
运行代码及资源摘要完全一致，差异证明随包提供。真实桌面测试包与最终包的摘要分别记录，
不会把文档重包直接宣称为首轮GUI安装过的归档。

验证失败的中间尝试保留在本地研究证据，最终范围以
[release-r41-verification.json](release-r41-verification.json)中的收据为准。
Cognition有3项依赖上游私有历史语料的可选检查明确跳过，不计为通过。
未验证真实云模型、SSH、外部记忆服务或rc.3性能基准；没有修改正在使用的用户DSH。
