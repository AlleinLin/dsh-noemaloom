# 全局品牌与首页文案

在「设置 → Nexus → 外观与阅读 → 品牌与首页」修改侧栏品牌文字与颜色、首页标题、首页徽标开关及文字。颜色同时支持原生色板和六位十六进制输入。输入立即在当前窗口本地预览；只有「保存外观」才写入全局配置。关闭页面或切换设置分类撤销未保存预览。

每项都有独立默认按钮。标题和徽标恢复默认后跟随宿主界面语言；默认品牌复用宿主 DeepSeek 原生字标及其 HARNESS 副标，自定义文字使用独立的圆润无衬线字体，正文和控件字体不变。生成的品牌图标、Claude 主题及模型/供应商名称保留原有含义。

设置使用资源外观的 revision CAS 保存。文案按 React 文本渲染，不解释 HTML。侧栏使用原生 `sidebar.brand.name` 槽位，注册前保留默认组件，由 React 正常渲染；rc.2 首页只提供品牌图标槽位，因此首页组件只沿自己的图标节点找到所属 headline，穿过正式槽位的 `display: contents` 包装定位相邻标题和徽标，挂载自有 React 文本节点，卸载时恢复宿主语言节点。它不监听或替换整个页面文字。

标题与徽标使用固定字号和可换行布局；会话标题和视图栏留在各自分栏的布局与滚动边界内，顶部固定兼容正式槽位包装与直接子节点。子代理导航留在其原生会话滚动区域的顶部，不依赖全局 fixed 定位。设置区使用一致的标签和控件列，窄区域换为单列。
