# R40：子代理上下文压缩

修复 DSH 0.2.1-rc.3 在子代理中不发布宿主命令目录，导致原生 `/compact`
不出现在菜单的问题。使用官方客户端命令贡献补齐子代理 `/compact`；
主代理继续使用其原生命令。命令不经过聊天发送，不会误发到父会话。

在原生和 Codinput 输入工具栏加入“压缩”按钮。面板显示当前会话身份、
实际占用、自动阈值、压缩模型和操作结果，可直接压缩和修改全局或当前会话设置。
关闭面板不取消已开始的压缩，同会话多个视图共用一个操作状态和一个弹窗。
未知结果保留原请求编号，不另发重复压缩。
窄侧栏的原生输入工具行自动换行，避免权限、电脑操作与压缩按钮互相覆盖。

宿主提供统一压缩后端，覆盖没有挂载 Noemaloom 压缩器的自定义预设、
旧预设和已恢复的原生子代理。预设自己的压缩器优先；每次请求只由一个所有者维护，
逐步读取全局→工作区→当前会话的实时阈值和压缩模型。
原有显式工具禁用和只读权限仍有效。

已结束的子代理通常没有存活 Agent。状态读取使用正式 Session 的只读重放；
手动压缩通过宿主正式 resume 接口获取临时维护句柄，提交后释放。
不会投递新消息或启动子代理推理；与真正的继续请求通过宿主持久化写锁互斥。
fork 子代理保留宿主记录的准确继承边界和插件消息解释器；元数据缺失时明确报错。

`compact_context` 继续只作用于准确的调用智能体。增加稳定的模型指导，
包括 status、手动压缩、回执核对以及 PTC SDK 调用方式。
手动维护失败返回可核对的结果；不会因为打开页面或读取状态停止子代理。

验收与交付证据见 `release-r40-verification.json`。

最终验证：2382 项回归，0 失败、0 跳过；9 项真实桌面检查通过。
包含主/子输入框并存、子代理 /compact、按钮、97% 压力下自动压缩、
运行中自压缩、全局阈值保存生效、原生/Codinput 输入框和窄栏无重叠。
桌面模型调用使用本地确定性适配器；未调用用户云端网关或评估云模型摘要质量。
未重启或改写用户正在使用的 DSH、代理、账号及会话。
