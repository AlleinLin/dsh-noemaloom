# Auxiliary Failure Audit

Scope: 15 plugin-owned entry-point families listed below. This is a bounded source audit, not a claim that every external dependency has been audited.

Four primary propagation risks were repaired: automatic context preparation, optional memory preparation, live command observation, and the shared domain-event notification outlet. Supporting fixes preserve asynchronous self-maintenance error identity and prevent detached diagnostic logging from rejecting again. Ordinary tool errors already have a host-owned failed-result path; they are not evidence that a tool exception terminates a turn.

The reported trace `trace_f93e893a-8221-4c7c-9733-0b9cae110ff7` was not found locally. Source confirms that an exact provider `RATE_LIMITED` alias could become `NX_INTERNAL_FAILURE`; it also confirms that local resource leases use a branded `NexusError('RATE_LIMITED')`. These are code findings, not attribution of the remote incident.

## Host Tool Propagation Evidence

The installed host implementation in `node_modules/@deepseek-ai/dsh-tools/lib/types/index.js` has the relevant boundaries:

- `dispatchScheduledExecution()` awaits the `tools/execute` waterfall and catches failures as `final-result` with `toolErrorResult(error)`.
- `finalizeScheduledExecution()` also catches post-execute failures as tool error results.
- `dsh-agent-loop/lib/index.js:appendToolResult()` appends `result.content` and `result.isError` as the durable tool result that enters the next model request.

Accordingly, `nexus_<domain>.execute()` throwing `toHarnessError()` is a model-visible tool failure, not a turn-level throw. The real-loop regression makes both a parent and actual child receive that failed tool result and complete the following model step with one tool execution each. Read failures and unknown write effects remain distinct coded results; no observer converts either into success.

## Boundaries Preserved

Provider `RATE_LIMITED`, `RATE_LIMIT_EXCEEDED`, and `TOO_MANY_REQUESTS` normalize to `RATE_LIMIT` / `NX_GATEWAY_RATE_LIMIT`; a branded local lease error does not acquire provider retry semantics. Explicit user/native cancellation, actual host permission/budget denial, pending effects, and uncertain official replacement remain authoritative. Auxiliary provider auth/subscription/quota failure can defer only that optional maintenance, with no provider retry and no claim of successful compression.

Deferral is not overflow recovery. A request that cannot fit, lacks current window proof, has another unresolved official owner, or has unknown official effects remains stopped with a coded recoverable reason. Recovery never replays a completed tool, summary intent, or uncertain official mutation.

Only validated codes, provenance, HTTP status, bounded request IDs, and retry delay (at most one day) cross the added metadata boundary. Provider bodies, prompts, credentials and exception text are not copied.

All new model fixtures are local adapters; no external model request is required. This edit batch is handed off frozen for one coordinated typecheck/build/test/desktop verification pass. No validation result is asserted by this document.
