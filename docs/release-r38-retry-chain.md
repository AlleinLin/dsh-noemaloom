# R38：重试链持久化修复

连续模型重试可能让会话再次打开时失败，错误为
`SessionFormatError: llm/retry must keep one retryId per policy chain`。
旧实现每次重试都生成新 ID，而上游 v4 格式要求同一
`turn/step/provider/policyKey` 链保持一个 ID。内存中可以继续运行，
完整历史恢复时才会被关系校验拒绝。

## 修改

- 每条策略链复用自己的 retryId，retry 从 1 连续递增；相应 retry-started 使用相同的 ID 和次数。
- 跨策略继续共用持久化总预算。切换设置、重载插件或恢复原策略均不会补充预算。
- 投影缓存版本从 1 改为 2，旧缓存按完整事件重建。
- 测试接入与宿主一致的官方格式目录，先编码全部事件，再执行严格完整恢复。
  该依赖仅用于开发验证，不增加运行时依赖。
